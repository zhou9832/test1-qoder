模块采用标准 Spring Boot 分层结构：入口类 `TaskBoardApplication` 通过 `@SpringBootApplication` 启动；控制器层 `controller/`（HealthController、ProjectController、StatsController、TagController、TaskController、TimeLogController）暴露 `/api/*` REST 端点，依赖注入 `service/` 中的业务逻辑，再调用 `repository/` 中继承 `JpaRepository` 的数据访问接口，实体定义在 `entity/` 下（Project、Tag、Task、TimeLog）。所有 HTTP 响应经 `dto/ApiResponse<T>` 统一包装（code/message/data），请求体 DTO 与响应 DTO 分离。全局异常处理由 `common/GlobalExceptionHandler` 集中捕获 `BizException`，分页结果统一为 `PageResult<T>`。数据初始化通过 `application.properties` 中 `spring.sql.init.mode=always` 配合 `schema-locations` 与 `data-locations` 在应用启动时按序执行 `schema.sql` 建表与 `data.sql` 种子数据，并启用 H2 Console（`/h2-console`）。构建由 Gradle Kotlin DSL (`build.gradle.kts`) 管理，测试位于 `src/test/java/com/taskboard/controller/`，基于 JUnit Platform。
