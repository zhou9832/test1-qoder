模块采用标准 Spring Boot 分层结构：入口类 `TaskBoardApplication` 通过 `@SpringBootApplication` 启动；控制器层 `controller/HealthController` 暴露 `/api/health` 健康检查端点，`ProjectController` 在 `/api/projects` 下提供 GET/POST/PUT/DELETE 操作，依赖注入 `service/ProjectService` 调用 JPA Repository `repository/ProjectRepository`（`entity/Project` 为 JPA 实体）；所有 HTTP 响应经 `dto/ApiResponse<T>` 统一包装（code/message/data）。数据层通过 `application.properties` 中 `spring.sql.init.mode=always` 配合 `schema-locations` 与 `data-locations` 在应用启动时按序执行 `schema.sql` 建表与 `data.sql` 种子数据，并启用 H2 Console（`/h2-console`）。构建由 Gradle Kotlin DSL (`build.gradle.kts`) 管理，使用 Spring Boot Web/JPA/Validation/Test Starter，测试位于 `src/test/java/com/taskboard/controller/`，基于 JUnit Platform。
