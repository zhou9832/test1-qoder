- 所有 HTTP 响应统一通过 `ApiResponse<T>` 包装，使用静态工厂 `success()` / `error()` 构造，而非直接返回业务对象。
- REST 控制器类使用 `@RestController` + `@RequestMapping("/api/...")` 集中声明接口前缀，具体路径由方法级 `@GetMapping`/`@PostMapping` 等注解追加。
- 数据库初始化采用 Spring SQL Init 机制，通过 `application.properties` 中的 `spring.sql.init.schema-locations` 与 `data-locations` 分别指定建表脚本与种子数据。
