模块采用标准 Spring Boot 分层结构：入口 `TaskBoardApplication` 通过 `@SpringBootApplication` 启动；控制器层 `controller/HealthController` 暴露 `/api/health` 端点，返回统一包装体 `dto/ApiResponse<T>`；数据层通过 `spring.sql.init` 在应用启动时按顺序执行 `schema.sql` 与 `data.sql` 初始化 H2 内存库，并开启 H2 Console（`/h2-console`）。依赖方向单向：controller → dto，无 service/dao 层。构建由 Gradle Kotlin DSL (`build.gradle.kts`) 管理，使用 Spring Boot 4.0.1、JPA + H2、Validation Starter，测试基于 JUnit Platform。
