模块为独立的前端工程，采用 Vite 作为构建与开发服务器，React 19 + TypeScript 作为运行时。
- 入口：`src/main.tsx` 通过 `ReactDOM.createRoot` 挂载 `<App />` 到 `index.html` 的 `#root` 节点，并引入全局样式 `App.css`。
- 应用壳：`src/App.tsx` 使用 `react-router-dom` 的 `BrowserRouter`/`Routes` 注册根路由 `/` → `HomePage`、`/projects` → `ProjectsPage`，并通过 `antd` 的 `ConfigProvider` 注入中文语言包（`zh_CN`）。
- 页面：`src/pages/HomePage.tsx`、`src/pages/ProjectsPage.tsx` 基于 Antd 的 `Layout`（Header/Content/Footer）+ `Typography` 搭建页面骨架。
- 构建配置：`vite.config.ts` 启用 `@vitejs/plugin-react`，并在 dev server 中将 `/api` 代理到 `http://localhost:8081`，表明后端服务运行在 8081 端口。
- 类型声明：`src/vite-env.d.ts` 供 Vite 解析 `.tsx` 中的 JSX 类型；`tsconfig.json` 管理 TS 编译选项。
