模块为独立的前端工程，采用 Vite 作为构建与开发服务器，React 19 + TypeScript 作为运行时。
- 入口：`src/main.tsx` 通过 `ReactDOM.createRoot` 挂载 `<App />` 到 `index.html` 的 `#root` 节点。
- 应用壳：`src/App.tsx` 使用 `react-router-dom` 的 `BrowserRouter`/`Routes` 注册根路由 `/` → `HomePage`，并通过 `antd` 的 `ConfigProvider` 注入中文语言包（`zh_CN`）。
- 页面：`src/pages/HomePage.tsx` 基于 Antd 的 `Layout`（Header/Content/Footer）+ `Typography` 搭建首页骨架。
- 构建配置：`vite.config.ts` 启用 `@vitejs/plugin-react`，并在 dev server 中将 `/api` 代理到 `http://localhost:8080`，表明后端服务运行在 8080 端口。
- 样式：全局样式集中在 `src/App.css`，由 `main.tsx` 统一引入。
- 类型声明：`src/vite-env.d.ts` 供 Vite 解析 `.tsx` 中的 JSX 类型。
