独立的前端工程，目录按功能分层：`src/main.tsx` 通过 `ReactDOM.createRoot` 挂载 `<App />`；`src/App.tsx` 使用 `react-router-dom` 注册根路由（`/` → HomePage、`/projects` → ProjectsPage），并通过 antd 的 `ConfigProvider` 注入中文语言包 `zh_CN`。
- 页面层：`src/pages/` 下每个业务域一个文件（HomePage、ProjectsPage、TasksPage、TagsPage、StatsPage、TimeLogsPage），均基于 Antd Layout（Header/Content/Footer）+ Typography 搭建骨架，样式采用同名 `.module.css` 文件。
- 组件层：`src/components/PageState.tsx` 封装 loading/error/empty 三种页面状态供各页面复用。
- API 层：`src/api/client.ts` 暴露 `ApiClient` 类与模块级单例 `apiClient`，统一处理 GET/POST/PUT/PATCH/DELETE，默认 baseURL 为 `/api`；`src/api/schema.d.ts` 提供后端响应类型声明。
- 构建配置：`vite.config.ts` 启用 `@vitejs/plugin-react`，dev server 将 `/api` 代理到 `http://localhost:8081`，表明后端服务运行在 8081 端口。
- 类型声明：`src/vite-env.d.ts` 供 Vite 解析 JSX 类型；`tsconfig.json` 管理 TS 编译选项。
