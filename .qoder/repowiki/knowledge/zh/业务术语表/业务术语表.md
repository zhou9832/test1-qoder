### TaskBoard
- 定义：本 monorepo 所构建的任务看板应用，包含 Spring Boot 4 后端（server/）与 React 19 前端（web/）两个子模块，对外暴露 `/api/health` 健康检查接口。

### Monorepo
- 定义：本项目采用单仓库多模块结构，后端 server/ 与前端 web/ 同属一个 Git 仓库，共享根级 README 与 .gitignore。

### ApiResponse<T>
- 定义：后端统一的 HTTP 响应包装类，所有接口返回值均包裹在此泛型结构中，便于前端统一处理成功/失败状态。
- 别名：统一响应包装

### 健康检查接口
- 定义：后端提供的 `GET /api/health` 端点，用于验证服务是否存活并可正常响应请求，是前后端联调的首要验证入口。
- 别名：Health Check、/api/health

### 章程
- 定义：项目的环境与实现基线规范文件 `.qoder/rules/00-project-charter.md`，规定了 Java/Spring Boot/前端技术栈、包名约定、数据库策略等强制要求。
- 别名：project charter、00-project-charter.md
