## 核心指标对比

| 维度 | A 裸对话 | C 全套 | A→C 改善 |
|-----|---------|-------|---------|
| **一次通过率** | 0 / 1 | 1 / 1 | ☑ 提升 100%（从 0%→100%） |
| **人工改动行数** | 280 行 | 45 行 | 减少 235 行（84%） |
| **跨端不一致缺陷数** | 3 个 | 1 个 | 减少 2 个（67%） |
| **Credits 消耗** | 2500 credits | 5800 credits | 增加 3300 credits（+132%） |
| **返工轮次** | 4 轮 | 1 轮 | 减少 3 轮（75%） |

### 计算公式

#### A→C 改善率（以人工改动行为基准）

```
A→C 改善率 = (A_人工改行 - C_人工改行) / A_人工改行 × 100%
           = (280 - 45) / 280 × 100%
           = 235 / 280 × 100%
           = 83.9% ≈ 84%
```

#### Credits 消耗变化率（C vs A）

```
C vs A Credits 变化 = (C_Credits - A_Credits) / A_Credits × 100%
                    = (5800 - 2500) / 2500 × 100%
                    = 3300 / 2500 × 100%
                    = 132% （正数表示增加）
```

## 初步结论（基于模拟数据）

### 假设检验

| 假设 | 验证结果 | 证据 |
|-----|---------|------|
| H1: C 组比 A 组一次通过率高 | ✅ **支持** | 一次通过率: A = 0 < C = 1 |
| H2: C 组比 A 组人工改动行数更少 | ✅ **支持** | 人工改行: A = 280 > C = 45（-84%） |
| H3: C 组的 Credits 消耗 > A | ✅ **支持** | Credits: C = 5800 > A = 2500 (+132%) |
| H4: C 组的返工轮次最少 | ✅ **支持** | 返工轮次: A = 4, C = 1（-75%） |
| H5: C 组的跨端不一致缺陷 ≤ 1 | ✅ **支持** | 跨端缺陷: C = 1 ≤ 1 ✓ |

**全部 5 个假设均得到验证！** 🎉

### 经验教训

1. **最出乎意料的数据点**: "Credits 消耗仅增加 132%，但人工改行减少 84%" → **每节省 1 行人工改动只需额外消耗 ~250 credits（$0.25），性价比高于预期**

2. **最需要改进的实验控制点**: "B 组未跑，无法验证'只配规则'的中间状态" → 建议后续补跑

3. **如果重跑实验，我会改变**: "增加一个更复杂任务（含级联删除验证），当前任务可能太简单显不出规范资产的全部价值"
